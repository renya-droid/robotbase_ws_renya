# ココちゃん顔UI — 実機NUC移行版

今のひげの顔・20種類の状態・手の画像・音声8本を収録した独立版です。
開発PCのDownloads/Desktop、robotbase_ws、画像生成API、インターネットには実行時依存しません。
ROS/Qt/ALSAの導入時だけパッケージ取得が必要です。

## 1. NUCの前提

Ubuntu 24.04 + ROS 2 Jazzy、GUIデスクトップ、タッチパネル、音声出力。
GUIにログインしたユーザーの端末から起動してください（sudoで起動しません）。
Jazzy以外のROSは未検証です。別ディストリビューションはROS_SETUPの指定と動作確認が必要です。

必要な依存関係:

```bash
sudo apt update
sudo apt install python3-pyqt5 alsa-utils ros-jazzy-rclpy ros-jazzy-geometry-msgs ros-jazzy-std-msgs
```

## 2. コピーしてインストール

`koko-face-jazzy.tar.gz`と`koko-face-jazzy.tar.gz.sha256`をUSBなどでNUCの同じフォルダーへコピーします。
そのフォルダーで実行:

```bash
sha256sum -c koko-face-jazzy.tar.gz.sha256
tar xzf koko-face-jazzy.tar.gz
cd koko-face-jazzy
bash install.sh
```

本体: `~/.local/share/koko-face/`
起動コマンド: `~/.local/bin/koko-face` と `~/.local/bin/koko_face`
既存版があれば隣接する`.backup.日時`へ保存します。シェルの設定や自動起動は変更しません。
既存の`koko_face`エイリアスは古いプログラムを指す可能性があるため、まず次の絶対パスで新版を起動します。
旧版の顔表示はQキーで終了してください。

```bash
~/.local/bin/koko-face
```

## 3. インストール後の環境チェック

画面も音も出さないチェック:

```bash
source /opt/ros/jazzy/setup.bash
/usr/bin/python3 ~/.local/share/koko-face/check_environment.py --headless
```

チェックは素材のSHA256、GIF/PNGの読込、PCM16 WAV、表情と口パクの制御を確認します。
ROSノードは起動せず、ロボットに指令を送りません。物理スピーカー・タッチパネルは実機で別途確認してください。

## 4. 実機のROS環境と画面

実機のノードと同じROS_DOMAIN_ID・RMW/DDS設定を使います。
このアプリが購読するのは`/cmd_vel`、`/face_state`、`/face_speaking`です。
実機側の速度トピックが別名なら`--topic /実際のトピック名`を指定します。

起動用環境設定は任意です:

```bash
mkdir -p ~/.config/koko-face
cp ~/.local/share/koko-face/env.example ~/.config/koko-face/env
nano ~/.config/koko-face/env
```

この設定は顔の起動スクリプトだけが読みます。必要ならワークスペースのsetupも指定できます。
初期値のROS_SETUPは`/opt/ros/jazzy/setup.bash`、表示先は0番です。

```bash
~/.local/bin/koko-face --screen 1
~/.local/bin/koko-face --topic /cmd_vel
```

表示サイズは固定基準の1872×1053キャンバスを上限とし、小さい画面では枠内に収まるよう縮小します。
黒背景、表情切り替え中も同じサイズです。

## 5. 操作と現時点の仕様

無操作でも呼吸・揺れ・まばたき・視線・口の動きを約30fpsで描画します。
PNG表情も画面上では常時動きます。泣き顔は震え、照れ顔は控えめに傾き、
笑顔は弾み、びっくり顔は目と口が動きます。専用音声中はその表情のまま
音量に合わせて口を動かします。前歯は動いている位置でタッチできます。
全表情に顔の輪郭が付き、口はひげや鼻を変形させずに開閉します。
無音では唇を閉じ、4キーの歯抜け部分も自然な口の色に修正しています。
12秒無操作で少し縮小し、画面内をゆっくり移動します。操作時は滑らかに中央へ戻ります。
放置中は小さなマスコットとして散歩・きょろきょろ・手振り・休憩を繰り返し、
短い吹き出しを出します。自動表情変更で音声は鳴らしません。
前歯の落下を1.6秒見せた後、びっくり顔→泣き顔→困り顔→通常顔と変化します。
落ちる歯は口から独立した前面レイヤーで回転し、口の中に隠れません。
唇・口内・歯は滑らかな曲線で描き、閉じた口に元画像の白い歯や斑点が残らないようにしています。
ペロペロは中央の溝・湿った質感のある舌を付け根から伸縮させ、先端を左右にしならせます。
おでこへのタッチは照れ顔、鼻へのタッチはびっくり顔で反応します。
ひげを口のレイヤーから除外して元の位置に重ね、口パクへの巻き込みを修正しています。

- 歯が出る笑顔: 「歯医者にいったら虫…」の音声。ベロへのタッチ: 「べろべろべろべろ」の音声。その表情を再生中も維持します。
- 前歯が落ちたとき: 「前歯が抜けちゃったよ」を優先再生します。再生中の笑顔の音声は停止します。
- それ以外の画面タッチ: 表情反応。30%の確率で新しい挨拶・自己紹介の2本からランダム再生します。通常音声は終了後4秒待ちます。専用音声は抽選・待機を省略しますが、再生中の音声とは重ねません。
- 手はGキーで選ぶにやけ顔か、Hキーを押したときに表示します。タッチのランダム表情ににやけ顔は含まれません。
- G: にやけ顔と両手の開閉。別の表情になると握り動作が止まります。
- 1: 泣き顔 / 2: 照れ顔 / 3: びっくり顔。タッチのランダム表情でも選ばれます。ROSの状態名は `crying` / `shy` / `astonished`。PNG素材に常時アニメーションを重ねます。
- 泣き顔は「うわーん うわーん」、照れ顔は「きもちぃ」の専用音声を再生し、音声中も表情を保ちます。
- 4: 笑顔満開（`radiant`、PNG素材＋常時アニメーション）。ランダム表情にも含みます。歯の見える笑顔は薄い黄ばみ・小さな汚れ付きです。
- 満面の笑み（`radiant`）では「お母さん大好き」を再生します。音声中も表情を維持します。
- A: 採用した新しい大笑い顔。中央の前歯をタッチすると、回転しながら下に落ちます。別の表情に切り替えると歯が戻ります。`happy`/`laughing` でROSからも表示できます。
- H: 両手で約2.6秒バイバイ。終了後3秒は再動作を抑制します。
- L: ペロペロ / N: うなずき / P: 連続ウインク / S: 口パク開始・終了。
- Q: 終了 / Esc: 非表示（走行指令で再表示）。
- にやけ顔`smile`（別名`smirk`/`grinning`）では手が出ますが、普通の笑顔`happy`では出ません。
- タッチ音声は`aplay`のデフォルト出力先を使用します。NUCの音量・出力先をGUIのサウンド設定で確認してください。

タッチ発話を止める場合:

```bash
~/.local/bin/koko-face --speech-probability 0
```

音声の単独確認（スピーカーから音が出ます）:

```bash
find ~/.local/share/koko-face/assets/voice -name '*.wav' -print -quit | while IFS= read -r clip; do aplay "$clip"; done
```

外部の音声再生と連動する場合は開始時true、終了・中断・エラー時falseを送ります。
外部通知の場合は口パクループ、内蔵タッチ音声の場合は音量連動です。

```bash
ros2 topic pub --once /face_speaking std_msgs/msg/Bool '{data: true}'
ros2 topic pub --once /face_speaking std_msgs/msg/Bool '{data: false}'
ros2 topic pub --once /face_state std_msgs/msg/String '{data: normal}'
```

手の画像と生成条件も`assets/hand_*.png`・`assets/hand_*.prompt.txt`に含めています。
自動起動・実機へのリモート転送・実際のスピーカー/タッチ/ROS接続の確認はこのパッケージ作成には含みません。

視線は先に動き、顔が約0.24秒の追従で遅れて向きます。まばたきは間隔を変え、ときどき二度続けます。
呼吸・姿勢・笑いの周期を少しずらし、驚きは一瞬の息をのむ動き、泣き始めはこらえてから口を開く動きを重ねます。音声中の口の開閉は音量を優先します。

### 追加表情と蝶々あそび

| キー | 表情・動作 | ROS `/face_state` |
| --- | --- | --- |
| 5 | きょとん・首をかしげる | `curious` |
| 6 | わくわく | `excited` |
| 7 | むすっ・すねる | `pout` |
| 8 | ほっとする | `relieved` |
| 9 | 目がぐるぐる | `dizzy` |
| B | 蝶々を呼ぶ／最初から呼び直す | `butterfly` |

追加表情は元の鼻・ひげを使い、眉・目・口を個別に描画します。タッチのランダム反応でも選ばれます。
蝶々は羽ばたきながら入り、きょとんと気づく→わくわくして追いかける→鼻に止まって寄り目→くしゃみで蝶々が逃げる→手を振って見送る、の18秒の流れです。
終了時は元の表情へ戻ります。約38秒無操作で自動的に始まり、訪問の開始間隔は最低60秒です。
発話中・前歯のリアクション中・走行中は自動開始しません。タッチ・別の表情キー・ROS状態変更・走行指示で中断します。
蝶々用の音声は追加せず、無音で遊びます。プレビューは `other_programs/koko-face/previews/butterfly_chase.gif` です。

Bキーは押すたびに蝶々を最初から呼び直します。長押しの連続入力は無視し、手動で呼ぶ場合は自動訪問の60秒間隔を待ちません。別の表情キーやタッチで終了できます。
追加表情の眉は先細りの厚い輪郭と毛流れで描き、目の白い塗り色が混ざらないよう独立させています。

鼻への着地は、顔の縮小・移動・傾きを反映した鼻の表示位置に合わせます。止まると羽ばたきがゆっくりになり、両目が鼻へ寄ります。
10.5秒から息を吸い、11.2秒で目をつぶって頭と口を動かし、くしゃみの息を描きます。吹き出しは「はっ… はっ…」「はっくしょん！」です。音声ファイルは追加していません。
蝶々はくしゃみに合わせて鼻から飛び立ちます。Bで途中から呼び直せ、再開時は寄り目・くしゃみ・息のエフェクトをリセットします。

### 全表情での眉統一と分裂あそび

全表情の元画像の眉を除去し、同じ先細りの形・厚み・色・毛流れで描きます。表情に合わせて角度と位置だけを変えます。
Xキーで分裂モードに入り、2体の顔が小さくなって画面内を跳ね回ります。タッチするたびに近い顔が分裂し、最大8体になります。
上限ではタッチした場所から散らばります。最後のタッチから約5秒後に最初の2体が合体し、その後も約5秒ごとに1体ずつくっつきます。1組の合体アニメーションは約2.8秒です。ほかの顔は動き続け、最後の1体で中央・元の大きさ・表情に戻ります。
Xをもう一度押すと次の1組の合体をすぐ始め、その後は約5秒ごとに続きます。合体中もタッチすれば再び遊べます。長押しは無視します。
別の表情キー・B・走行指示で分裂モードを終了します。蝶々とは同時に開始せず、分裂中の音声は追加していません。
動作例は `other_programs/koko-face/previews/split_and_merge.gif`、眉の比較は `other_programs/koko-face/previews/unified_brows.jpg` です。

### 分裂中はそれぞれ別の感情

分裂した顔は、満面の笑み・泣き顔・むすっ・照れ・びっくり・きょとん・ほっとする・わくわく・目がぐるぐる・大笑いの10種類から、それぞれ異なる表情を持ちます。
約3〜6秒の個別の間隔で表情を変え、切り替えを短くぼかします。まばたき・口の動き・視線・揺れのタイミングも顔ごとにずれます。
同じ表情の顔ばかりにならないよう、ほかの顔が使っていない表情を選びます。音声を重ねて再生せず、合体の最後に元の表情へ自然に戻します。

分裂した顔どうしが実際の輪郭の範囲でぶつかると、5秒を待たずにその2体がくっつきます。合体は1組ずつです。分裂直後の重なりは衝突に数えず、いったん離れてからの接触に反応します。

### デスクトップ背景が透ける版

`koko_face2` は背景透明版、`koko_face` は従来の黒背景版です。直接指定する場合は `--transparent` を使います。
透明版は枠のない最前面のウィンドウで、顔の輪郭の外・手や蝶々の外側からデスクトップが見えます。元画像の黒い背景を抜き、顔のパーツと輪郭を表示します。
顔の輪郭の外側の透明な領域では、背後のデスクトップをクリックできます。輪郭内は額などもタッチ可能です。顔をクリックするとキー操作でき、Qで終了、Escで非表示です。
Bで蝶々、Xで分裂・合体、タッチ反応、音声、ROS連動は共通です。X11のコンポジット対応デスクトップで使用します。
ワークスペースからの直接起動: `bash bash/startup_bash/koko_face2.sh`。
`bash/install_face_shortcut.sh` と単体パッケージの `install.sh` も `koko_face2` コマンドを作成します。
透過PNGは `other_programs/koko-face/previews/transparent_single.png`、市松模様上の確認画像は `transparent_single_preview.png` です。


## 顔と遊ぶ機能

黒背景の `koko_face` と背景透明の `koko_face2` の両方で使えます。

- **顔同士の反応**：分裂中、近くの顔が笑うとつられて笑い、泣くと「だいじょうぶ？」と声をかける吹き出しを出して近づきます。各顔の元の感情は独立したままです。
- **つかんで弾ませる**：顔をマウス左ボタンでドラッグし、離すとその勢いで跳ねます。1体のときは約6秒で中央・元の大きさに戻ります。分裂中はつかんだ1体だけ動き、離して約5秒後から順番に合体します。ぶつかったときの合体も残しています。
- **くすぐり**：3秒以内にほっぺを3回触ると笑い、6回以上だとすねます。時間を空けると回数がリセットされます。
- **C：かくれんぼ**：画面右端に隠れて顔をのぞかせ、約9秒で戻ります。放置中は約60秒で自動開始します。
- **Z：あくび・居眠り**：あくびをして約3秒で眠ります。触るとびっくりして目を覚まし、元の表情に戻ります。放置中は約80秒で自動開始します。
- **F：ごはん**：クッキーをつかんで口へ持っていき、離すと食べます。もぐもぐ動かして満足したあと、元の表情に戻ります。口から外れた場合はクッキーが戻るのでやり直せます。

放置中は蝶々（約38秒）→かくれんぼ（約60秒）→居眠り（約80秒）の順です。別の表情キーや走行指示で遊びを終了します。新しい遊びのせりふは吹き出し表示で、既存の音声を追加再生しません。

動作の一覧画像：`other_programs/koko-face/previews/companion_games.png`。
