# ココちゃんの顔UI

移行ZIPの独立版を `other_programs/koko-face/` に収録しています。
ROSパッケージの再ビルドは不要です。

```bash
source ~/robotbase_ws_renya/bash/bash_alias1.sh
source ~/robotbase_ws_renya/bash/bash_alias2.sh
koko_face
```

ランチャー2では「ユーティリティ」の `koko_face` から起動できます。
ボタンが出ない場合はランチャーを起動し直してください。
端末用コマンドだけを追加する場合は、次を実行します（既存コマンドはバックアップ）。

```bash
bash ~/robotbase_ws_renya/bash/install_face_shortcut.sh
~/.local/bin/koko_face
```

実機の `robot.env` と同じROS Domain/RMW設定を使用し、`/cmd_vel`、
`/face_state`、`/face_speaking` を購読します。速度指令は送信しません。
表示先を変える場合は `koko_face --screen 1`、タッチ音声を止める場合は
`koko_face --speech-probability 0` を使用します。

Qで終了、Escで非表示、Gでにやけ顔、Hでバイバイ、Sで口パク切替です。
**Aで新しい大笑い顔**を表示します（通常の笑顔 `happy` にも採用）。
追加した3種類は **1で泣き顔、2で照れ顔、3でびっくり顔** を表示します。
泣き顔では「うわーん うわーん」、照れ顔では「きもちぃ」を再生します。
音声中もそれぞれの表情を維持し、終了時に同じ音声を繰り返しません。
**4で笑顔満開（radiant）**を表示します。これもタッチ時のランダム表情に含みます。
満面の笑みでは「お母さん大好き」を再生し、音声中もその表情を維持します。
歯が見える笑顔には薄い黄ばみと小さな茶色い汚れを加えています。
抜けた歯の跡は口の色のままで、落下する前歯にも同じ黄ばみが付きます。
タッチ時のランダム表情にも含まれます。ROSの `/face_state` にはそれぞれ
`crying`、`shy`、`astonished` を送信します。素材はPNGで、画面上では目・口・顔が常時動きます。
大笑い顔の中央の残っている前歯をタッチすると、歯が回転しながら落ち、穴が残ります。
そのときは「前歯が抜けちゃったよ」を優先再生します。笑顔の「虫歯」音声が再生中なら切り替わります。
音声中もタッチ可能です。別の表情に切り替えて戻ると歯が復活します。
ROSからは `/face_state` に `laughing` または `happy` を送って表示できます。
笑顔（happy）とにやけ顔（smile）は、前歯が1本抜けた歯並びを表示します。
タッチでも表情が変わります。歯が出る笑顔では「虫歯」、ベロへのタッチでは
「べろべろ」を再生し、その表情を音声中も維持します。それ以外のタッチでは
30%の確率で新しい挨拶・自己紹介の2本からランダム再生します。
専用音声は通常の4秒の待機や抽選を省略しますが、再生中の音声とは重ねません。
`--speech-probability 0` で専用音声も含めて無音になります。
音声の出力先はシステムのサウンド設定で選択します。
キーボードの7キーを押すと、誕生日の専用音声と笑顔を出します。
この音声はタッチ時のランダム再生には含まれません。

画面・音声を出さない検証:

```bash
source /opt/ros/jazzy/setup.bash
/usr/bin/python3 ~/robotbase_ws_renya/other_programs/koko-face/check_environment.py --headless
```

元パッケージの操作・依存関係は
[`other_programs/koko-face/README.md`](../other_programs/koko-face/README.md) を参照。
このワークスペースでは上記の起動スクリプトを使用します。

## 常時アニメーション

無操作でも約30fpsで呼吸・小さな揺れ・視線移動・まばたき・口の動きを描画します。
泣き顔は震え、照れ顔は傾きと控えめな口の動き、笑顔は弾む動き、
びっくり顔は大きな目と口の開閉になります。既存GIFの動きも残ります。
PNGの表情も画面上で常時動き、表情に合った目・口の変形を重ねます。
専用音声中はその表情を維持し、音量の強弱も口の動きに反映します。
音声のないときにも口は小さく動きます。

前歯のタッチは、顔全体の揺れと口の変形を逆変換して判定します。
動いている歯をそのままタッチできます。映像のプレビューは
[`continuous_motion.gif`](../other_programs/koko-face/previews/continuous_motion.gif) です。

全表情に耳・頬・あごを含む共通の顔の輪郭を描画します。
口は鼻・ひげ・あごから分離して動き、無音や休止時は歯を隠して唇を閉じます。
4キーの笑顔の歯抜け部分は、独立した暗い歯形を除去して口の中へ自然につなげました。

マウス移動・タッチ・キー入力・実機の移動が12秒ない場合は、5秒かけて少し縮小し、
顔が画面内をゆっくり移動します。操作すると約1.5秒で中央へ滑らかに戻ります。
移動中も顔の輪郭が画面内に収まり、前歯のタッチは実際の表示位置で判定します。

## マスコットらしい反応

- 前歯が落ちると「前歯が抜けちゃったよ」を再生し、1.6秒間は歯の落下を見せ、びっくり顔へ変化します。
  3.4秒後に泣き顔、8.4秒後に困り顔、14秒後に通常顔へ落ち着きます。途中でも表情を手動変更できます。
- おでこをなでると照れ顔と「きもちぃ」、鼻を触るとびっくり顔になります。
  素早い連続タッチでは従来どおり怒った表情になります。
- 放置中は画面の中で小さなマスコットになって散歩・きょろきょろ・手振り・休憩を
  繰り返します。短い吹き出しも出します。放置中の自動表情変更では音声を鳴らしません。
- ひげの暗い輪郭から明るい毛色まで口のレイヤーから除外し、元の位置に重ねるので、
  口パクにひげが付いてくる現象を抑えています。

反応と散歩の[動くプレビュー](../other_programs/koko-face/previews/companion_reactions.gif)は
左が歯抜け後の感情変化、右が放置中のマスコットです。時間を短縮して表示しています。

### 口まわりと舌の描画

口は `mouth_art.py` で唇・口内・歯を個別に描きます。古い歯のハイライトや画像の斑点を除去し、ひげだけを固定位置へ重ねます。
前歯は顔の変形・口のマスクから独立して描き、回転と重力を付けて下へ落とします。
ペロペロは生成した `assets/human_tongue.png` を使用し、付け根を固定して伸縮・屈曲します。古い舌のGIFは先頭フレームで止め、二重描画を防ぎます。

### 自然な動きのタイミング

- 視線は素早く反応し、顔は約0.24秒の時定数で追従します。更新間隔が変わっても追従速度を保ちます。
- まばたきは不等間隔にし、ときどき二度続けます。閉じる動きは速く、開く動きは少しゆっくりです。
- 呼吸・姿勢・笑いのリズムをずらし、目は短く視線を変えてからしばらく保ちます。
- 驚き顔は最初に息をのむ動き、泣き顔は少しこらえてから泣き始める動きを付けます。音声中は口の音量連動を優先します。

### 追加表情と蝶々あそび

| キー | 表情・動作 | ROS `/face_state` |
| --- | --- | --- |
| 5 | きょとん・首をかしげる | `curious` |
| 6 | わくわく | `excited` |
| 0 | むすっ・すねる | `pout` |
| 7 | 誕生日のお祝い音声と笑顔 | — |
| 8 | ほっとする | `relieved` |
| 9 | 目がぐるぐる | `dizzy` |
| B | 蝶々を呼ぶ／最初から呼び直す | `butterfly` |

追加表情は元の鼻・ひげを使い、眉・目・口を個別に描画します。タッチのランダム反応でも選ばれます。
蝶々は羽ばたきながら入り、きょとんと気づく→わくわくして追いかける→鼻に止まって寄り目→くしゃみで蝶々が逃げる→手を振って見送る、の18秒の流れです。
終了時は元の表情へ戻ります。約38秒無操作で自動的に始まり、訪問の開始間隔は最低60秒です。
発話中・前歯のリアクション中・走行中は自動開始しません。タッチ・別の表情キー・ROS状態変更・走行指示で中断します。
蝶々用の音声は追加せず、無音で遊びます。プレビューは `other_programs/koko-face/previews/butterfly_chase.gif` です。

Bキーは押すたびに蝶々を最初から呼び直します。長押しの連続入力は無視し、手動で呼ぶ場合は自動訪問の60秒間隔を待ちません。別の表情キーやタッチで終了できます。
追加表情の眉は先細りの厚い輪郭と毛流れで描き、目の白い塗り色が混ざらないよう独立させています。

鼻への着地は、顔の縮小・移動・傾きを反映した鼻の表示位置に合わせます。止まると羽ばたきがゆっくりになり、両目が鼻へ寄ります。
10.5秒から息を吸い、11.2秒で目をつぶって頭と口を動かし、くしゃみの息を描きます。吹き出しは「はっ… はっ…」「はっくしょん！」です。音声ファイルは追加していません。
蝶々はくしゃみに合わせて鼻から飛び立ちます。Bで途中から呼び直せ、再開時は寄り目・くしゃみ・息のエフェクトをリセットします。

### 全表情での眉統一と分裂あそび

全表情の元画像の眉を除去し、同じ先細りの形・厚み・色・毛流れで描きます。表情に合わせて角度と位置だけを変えます。
Xキーで分裂モードに入り、2体の顔が小さくなって画面内を跳ね回ります。タッチするたびに近い顔が分裂し、最大8体になります。
上限ではタッチした場所から散らばります。最後のタッチから約5秒後に最初の2体が合体し、その後も約5秒ごとに1体ずつくっつきます。1組の合体アニメーションは約2.8秒です。ほかの顔は動き続け、最後の1体で中央・元の大きさ・表情に戻ります。
Xをもう一度押すと次の1組の合体をすぐ始め、その後は約5秒ごとに続きます。合体中もタッチすれば再び遊べます。長押しは無視します。
別の表情キー・B・走行指示で分裂モードを終了します。蝶々とは同時に開始せず、分裂中の音声は追加していません。
動作例は `other_programs/koko-face/previews/split_and_merge.gif`、眉の比較は `other_programs/koko-face/previews/unified_brows.jpg` です。

### 分裂中はそれぞれ別の感情

分裂した顔は、満面の笑み・泣き顔・むすっ・照れ・びっくり・きょとん・ほっとする・わくわく・目がぐるぐる・大笑いの10種類から、それぞれ異なる表情を持ちます。
約3〜6秒の個別の間隔で表情を変え、切り替えを短くぼかします。まばたき・口の動き・視線・揺れのタイミングも顔ごとにずれます。
同じ表情の顔ばかりにならないよう、ほかの顔が使っていない表情を選びます。音声を重ねて再生せず、合体の最後に元の表情へ自然に戻します。

分裂した顔どうしが実際の輪郭の範囲でぶつかると、5秒を待たずにその2体がくっつきます。合体は1組ずつです。分裂直後の重なりは衝突に数えず、いったん離れてからの接触に反応します。

### デスクトップ背景が透ける版

`koko_face2` は背景透明版、`koko_face` は従来の黒背景版です。直接指定する場合は `--transparent` を使います。
透明版は枠のない最前面のウィンドウで、顔の輪郭の外・手や蝶々の外側からデスクトップが見えます。元画像の黒い背景を抜き、顔のパーツと輪郭を表示します。
顔の輪郭の外側の透明な領域では、背後のデスクトップをクリックできます。輪郭内は額などもタッチ可能です。顔をクリックするとキー操作でき、Qで終了、Escで非表示です。
Bで蝶々、Xで分裂・合体、タッチ反応、音声、ROS連動は共通です。X11のコンポジット対応デスクトップで使用します。
ワークスペースからの直接起動: `bash bash/startup_bash/koko_face2.sh`。
`bash/install_face_shortcut.sh` と単体パッケージの `install.sh` も `koko_face2` コマンドを作成します。
透過PNGは `other_programs/koko-face/previews/transparent_single.png`、市松模様上の確認画像は `transparent_single_preview.png` です。


## 顔と遊ぶ機能

黒背景の `koko_face` と背景透明の `koko_face2` の両方で使えます。

- **顔同士の反応**：分裂中、近くの顔が笑うとつられて笑い、泣くと「だいじょうぶ？」と声をかける吹き出しを出して近づきます。各顔の元の感情は独立したままです。
- **つかんで弾ませる**：顔をマウス左ボタンでドラッグし、離すとその勢いで跳ねます。1体のときは約6秒で中央・元の大きさに戻ります。分裂中はつかんだ1体だけ動き、離して約5秒後から順番に合体します。ぶつかったときの合体も残しています。
- **くすぐり**：3秒以内にほっぺを3回触ると笑い、6回以上だとすねます。時間を空けると回数がリセットされます。
- **C：かくれんぼ**：画面右端に隠れて顔をのぞかせ、約9秒で戻ります。放置中は約60秒で自動開始します。
- **Z：あくび・居眠り**：あくびをして約3秒で眠ります。触るとびっくりして目を覚まし、元の表情に戻ります。放置中は約80秒で自動開始します。
- **F：ごはん**：クッキーをつかんで口へ持っていき、離すと食べます。もぐもぐ動かして満足したあと、元の表情に戻ります。口から外れた場合はクッキーが戻るのでやり直せます。

放置中は蝶々（約38秒）→かくれんぼ（約60秒）→居眠り（約80秒）の順です。別の表情キーや走行指示で遊びを終了します。新しい遊びのせりふは吹き出し表示で、既存の音声を追加再生しません。

動作の一覧画像：`other_programs/koko-face/previews/companion_games.png`。
